# تطبيق قواعد الإصدار 3 (عزل القراءة حسب الدور)

## شنو تغيّر عن الإصدار 2
- الطبيب ما يكدر يقرأ: الرواتب، المصاريف، الجرد، الصندوق، الموردين، حسابات المختبر، طلبات الحجز. حتى لو حاول من خارج النظام.
- حسابات المختبرات (دفعات المختبر) للإدارة فقط.
- السكرتارية تقرأ كل العيادات مثل قبل، لأن المريض يتنقل بين العيادات والسجل موحّد.
- كل شي ثاني مثل الإصدار 2. الاختبارات: 113 ناجح، 0 فاشل.

## الترتيب مهم
1. **أولاً** ننشر النظام الجديد (بعد موافقتك)، لأنه يعرف يتعامل مع الأقسام الممنوعة.
   النظام القديم إذا انطبقت عليه هاي القواعد يعلق عند الطبيب على شاشة التحميل.
2. **بعدها** تطبّق القواعد من Cloud Shell:

```
mkdir -p ~/rules && cd ~/rules && curl -sL https://raw.githubusercontent.com/drhudaclinics/dr-huda-dental/v2-staging/security/firestore.rules.v3 -o firestore.rules && head -3 firestore.rules && echo '{"firestore":{"rules":"firestore.rules"}}' > firebase.json && firebase deploy --only firestore:rules --project huda-clinics
```

3. جرّب: افتح بحساب طبيب، لازم يشتغل عادي (لوحتي، المرضى، المواعيد، المختبر).

## الرجوع للإصدار 2 إذا صار أي شي

```
cd ~/rules && curl -sL https://raw.githubusercontent.com/drhudaclinics/dr-huda-dental/v2-staging/security/firestore.rules.v2 -o firestore.rules && head -3 firestore.rules && firebase deploy --only firestore:rules --project huda-clinics
```
