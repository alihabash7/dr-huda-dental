# النسخ الاحتياطي والاسترجاع

## أخذ نسخة (قبل أي تحديث)
1. ادخل النظام بحساب المالك.
2. القائمة ← **الإعدادات** ← **تنزيل نسخة احتياطية**.
3. ينزل ملف `نسخة-عيادات-التاريخ.json` يحتوي كل المجموعات (المرضى، العلاجات، الدفعات، المواعيد، الحسابات…).
4. احفظه بمكانين: Google Drive وعلى الموبايل.

يُنصح بنسخة أسبوعية، ونسخة قبل كل تحديث للنظام أو للقواعد.

## الاسترجاع
- الإعدادات ← **استرجاع من ملف** ← اختر ملف النسخة.
- الاسترجاع يعيد كتابة السجلات الموجودة في الملف بنفس معرّفاتها، ولا يحذف سجلات أُضيفت بعد النسخة.
- لا تسترجع إلا بعد التأكد من الملف الصحيح، وبحساب المالك.

## نسخ احتياطي تلقائي (اختياري)
يحتاج ترقية Firebase إلى خطة Blaze (دفع حسب الاستخدام، تكلفة شهرية قليلة جداً لحجم العيادات) لتفعيل النسخ اليومي التلقائي من Google Cloud.
